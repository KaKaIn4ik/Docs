# ADR-003: двухэтапный атомарный CSV

Дата: 26.10.2026. Статус: принято в проектной спецификации v1.0.

## Контекст
Нужны понятные ошибки, повтор импорта без копий и отсутствие частичного результата.

## Решение
CSV с обязательным UUID; upload/validate → подтверждение/commit. Импорт добавляет новые, пропускает полное совпадение, конфликтует с отличающимся содержимым UUID. Все новые контакты коммитятся одной транзакцией.

## Альтернативы
Частичный импорт труднее исправить; upsert может незаметно перезаписать чужие правки; дедупликация по имени/номеру объединяет разных людей. XLSX сложнее и не требуется.

## Последствия
Нужна временная защищенная область файлов, срок действия и повторная проверка перед коммитом. Подготовка CSV вручную сложнее из-за UUID. CSV-экспорт не заменяет backup.

## Когда пересматривать
Импорт существенно больше лимитов, необходимость массового редактирования или совместимости с заданным внешним форматом.
