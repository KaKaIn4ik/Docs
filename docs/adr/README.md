# Architectural Decision Records

ADR фиксирует не только выбор, но и причину, отвергнутые варианты и условия пересмотра. Статус «Принято в проектной спецификации» означает решение автора для этой версии; не означает, что пользователь отдельно одобрил каждую библиотеку.

- [ADR-001](001-application-stack.md): граница «с нуля» и стек.
- [ADR-002](002-contact-identity.md): идентичность, поиск и конкурентные изменения.
- [ADR-003](003-csv-import.md): перенос и повторный импорт.
- [ADR-004](004-durability-recovery.md): сохранность, восстановление и время.

Новые ADR не переписывают историю выбора: старый документ помечают замененным с ссылкой на новый. Изменение внешнего поведения требует также изменения OpenSpec.
