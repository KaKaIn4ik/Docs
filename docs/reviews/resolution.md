# Разбор замечаний независимого ревью

Дата: 26.10.2026. Первые отчеты сохранены без переписывания истории: их NO-GO относится к предварительному тексту с лимитом 50 MiB. Ниже исправления текущей версии.

| Замечание | Решение | Проверка в спецификации |
|---|---|---|
| Экспорт максимальной базы больше импорта | Лимит повышен до 1 GiB; добавлена верхняя оценка ≤1 056 000 000 байт + заголовок | docs/csv.md; приемка максимального round-trip |
| Потерян ответ первого upload | Повторная загрузка нового батча безопасна: upload не применяет контакты, старый батч истекает | docs/ui.md, api.md, csv.md; добавлен сценарий приемки |
| Разные точки начала RTO | Везде отсчет от обнаружения и регистрации инцидента | RS-04 и DR-01 |
| POST /session требует уже выполненного входа по общему правилу | Явно исключены GET и POST /session; CSRF на POST сохранен | docs/api.md; проверка входа до сессии |
| Истечение и очистка гоняются с commit | Единый порядок блокировок, проверка срока после блокировки, начатый вовремя commit завершается; очистка не удаляет занятый файл | docs/api.md, design.md; конкурентная приемка |

Исправления проверяются также свежим независимым финальным рецензентом. Все новые проверки поведения — план будущей реализации, не выполненные тесты приложения.

Финальное независимое ревью не выявило существенных блокеров. По двум необязательным рекомендациям дополнительно зафиксированы нумерация логических CSV-записей и полный набор полей объекта состояния импорта.
