# Elephant + Goldfish и LLM-expert review

Elephant — основной диалог: требования уточнены с пользователем, внешние сведения проверены по первоисточникам, решения перенесены в самодостаточные файлы. История чата не должна требоваться разработчику.

Goldfish — отдельные изолированные LLM-рецензенты без наследования истории диалога. Они читают только этот пакет и возвращают замечания. Выполняются две проверки: (1) понятность и возможность восстановить замысел; (2) архитектура, надежность и противоречия контрактов. Вердикты относятся к документам, не к несуществующей реализации. Автор проверяет замечания и фиксирует исправления. Итоги находятся в отдельных файлах этой папки.

Человеческая ответственность сохраняется: утверждение бизнес-требований и эксплуатационный допуск не заменяются вердиктом LLM. Если существенное замечание остается открытым, документация не называется готовой к реализации без оговорки.
