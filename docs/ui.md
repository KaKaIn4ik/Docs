# Браузерный интерфейс

Русский язык, настольный браузер, ширина от 1024 px. Поддержка — две последние стабильные версии Chrome и Firefox на момент приемки; версии фиксируются в отчете. Доступ по клавиатуре: подписи полей, видимый фокус, ошибки текстом, а не только цветом. Формы не используют django-admin как пользовательский интерфейс.

| Экран | Действия и состояния |
|---|---|
| Вход | Имя учетной записи, пароль, «Войти». Ошибка без раскрытия существования аккаунта. При истечении сессии — повторный вход; несохраненные поля остаются в текущей вкладке без записи в localStorage |
| Справочник | Поле «По имени / По телефону», текст запроса, «Найти», «Сбросить», «Добавить», «Импорт», «Экспорт», «Выйти». До поиска — страница общего списка. Таблица: имя, все телефоны, действия; пагинация по 50 |
| Результат | Все точные совпадения; тезки отдельными строками. Отдельные состояния «Загрузка», «Ничего не найдено», ошибка ввода, ошибка сервера. Поиск только по кнопке/Enter, не по каждому символу |
| Контакт | Имя, 1–10 телефонов, добавление/удаление поля телефона, «Сохранить», «Отмена». Даты с МСК. При 422 — ошибки у полей, ввод сохраняется |
| Конфликт | «Контакт изменен другим пользователем». Можно загрузить актуальную карточку после предупреждения о потере несохраненного ввода. Автоматического перезаписывания и скрытого слияния нет |
| Удаление | Диалог с именем и телефонами, «Удалить» и «Отмена», по умолчанию фокус на отмене. После 204 — возврат к списку; после 409 — обновить карточку |
| Импорт | Описание CSV и шаблон → выбор файла → «Проверить» → отчет/числа → «Применить». Пока запрос выполняется, повторная кнопка заблокирована. При потере ответа commit проверяется известный import_id. При потере ответа первой проверки, когда import_id еще неизвестен, разрешена повторная загрузка: предыдущий неподтвержденный батч истечет без применения |
| Экспорт | «Скачать весь справочник (CSV)». Состояние подготовки, понятная ошибка, скачивание phonebook.csv. Поисковый фильтр не ограничивает экспорт |

Сбой сети после сохранения означает неизвестный исход. UI проверяет контакт по заранее созданному UUID; PUT/DELETE сверяются чтением и версией. Не показывать «Сохранено» без серверного подтверждения. Пароли и содержимое справочника не отправляются в аналитику.
