# Spec Delta

## Purpose
Поиск контактов по полному имени или полному номеру без потери совпадений при неоднозначных данных.

## ADDED Requirements

### Requirement: SR-01 Поиск по имени
Система SHALL искать по точному совпадению NFC(trim(name)).casefold(). Внутренние пробелы, порядок слов, е/ё и знаки пунктуации не уравниваются. Возвращаются все контакты и все их телефоны.

#### Scenario: Регистр и края
- **WHEN** ищут «  иВАН Иванов  » при сохраненном «Иван Иванов»
- **THEN** контакт найден.

#### Scenario: Не подстрока
- **WHEN** ищут «Иван» при наличии только «Иван Иванов»
- **THEN** результат пуст.

#### Scenario: Два тезки
- **WHEN** несколько контактов имеют одно нормализованное имя
- **THEN** каждый присутствует ровно один раз с собственным UUID.

### Requirement: SR-02 Поиск по телефону
Система SHALL искать по равенству канонического телефона после нормализации CM-02. Возвращаются все владельцы совпавшего номера и полные наборы их телефонов.

#### Scenario: Формат
- **WHEN** ищут 8 (999) 123-45-67 при сохраненном +79991234567
- **THEN** возвращены все совпавшие контакты.

#### Scenario: Частичный номер
- **WHEN** ищут последние четыре цифры номера
- **THEN** возвращается 422 invalid_phone, поиск по подстроке не выполняется.

### Requirement: SR-03 Пустые и некорректные запросы
Система SHALL возвращать 200 и пустой список при отсутствии совпадений; пустой ключ, оба поисковых поля или неподдерживаемый параметр отклоняются с 422.

#### Scenario: Нет совпадений
- **WHEN** допустимый точный ключ отсутствует в справочнике
- **THEN** ответ содержит results=[] и count=0; UI показывает «Ничего не найдено».

#### Scenario: Нет ключа
- **WHEN** поиск отправлен с пустым именем
- **THEN** показана ошибка ввода, полный справочник не выдан.

### Requirement: SR-04 Пагинация
Система SHALL выдавать результаты страницами по контракту API: по умолчанию 50, максимум 100 контактов, сортировка по UUID по возрастанию. count отражает число всех совпадений в снимке одного запроса.

#### Scenario: Много совпадений
- **WHEN** найдены 120 тезок и запрошены limit=50, offset=50
- **THEN** возвращены контакты 51–100, count=120; повтор без изменений возвращает тот же порядок.
